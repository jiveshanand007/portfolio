I built this while I was still learning, out of curiosity about how real software gets made and
how a website is designed and put together end to end. Algorithms were what I was studying, so I
made them the subject: an interactive visualizer that shows sorting and graph algorithms step by
step.

There was no framework to lean on: I wrote the rendering engine myself in JavaScript on an HTML5
canvas, with colour-coded states so each comparison, swap and visit is easy to follow, and worked
out the layout and interaction design along the way. People I showed it to found the algorithms
easier to understand, and it taught me how a project goes from an idea to something live.
