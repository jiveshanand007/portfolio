I built an interactive visualizer to teach sorting and graph algorithms step by step. I wrote
the rendering engine myself in JavaScript on an HTML5 canvas, with colour-coded states so each
comparison, swap and visit is easy to follow. User interviews showed it made the algorithms
easier to understand, which is what it was for: making data structures and algorithms more
approachable.
